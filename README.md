# La Chronique — Refonte du site web

Refonte et développement du site web de **La Chronique**, un restaurant situé à Montréal.

L’objectif du projet est de moderniser le site tout en conservant l’identité du restaurant et en offrant une expérience utilisateur plus claire, actuelle et soignée.

> 🚧 Ce projet est actuellement en staging et toujours en développement.

## Portée du projet

- Refonte du site web
- Intégration responsive
- Amélioration de la structure du contenu
- Raffinement de l’interface et de l’expérience utilisateur
- Développement et intégration WordPress

## Technologies

- WordPress
- HTML5
- CSS / Sass
- JavaScript
- PHP

## Statut

**En cours — environnement de staging**

La version finale n’a pas encore été déployée sur le site de production du restaurant.

## À propos du projet

Ce projet a été réalisé dans le cadre d’un mandat de refonte du site web de La Chronique, avec une attention particulière portée à la combinaison du design visuel, de l’intégration front-end et de la gestion de contenu.

# La Chronique — Website Redesign

Redesign and redevelopment of the website for **La Chronique**, a restaurant based in Montréal.

The goal of the project is to modernize the website while maintaining the restaurant’s existing identity and creating a clearer, more polished user experience.

> 🚧 This project is currently in staging and is still under development.

## Project scope

- Website redesign
- Responsive integration
- Content structure and layout improvements
- UI/UX refinement
- WordPress development and integration

## Technologies

- WordPress
- HTML5
- CSS / Sass
- JavaScript
- PHP

## Status

**In progress — staging environment**

The final version has not yet been deployed to the restaurant’s production website.

## About the project

This project was developed as part of a website redesign mandate for La Chronique, with a focus on combining visual design, front-end integration and content management.
